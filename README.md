## 演示原型

[demo/index.html](demo/index.html) 是一个**单文件交互原型**：数据全部模拟生成，不依赖后端，也不需要构建工具，用浏览器直接打开即可。

覆盖 MVP 的 P0 范围：导入（模拟）、书架、章节切分、目录跳转、滚动阅读、字号 / 行距、日夜主题、进度保存与恢复。

操作要点：

- 书架卡片右上角的 **⋯** 悬停后会展开「重命名 / 删除」
- 阅读界面右上角是「目录」与「Aa 设置」
- **← →** 切换章节，**Esc** 返回书架
- 在设置里调整字号，可以观察正文重排后阅读位置如何保持不变

静态检查：

    node demo/check.mjs

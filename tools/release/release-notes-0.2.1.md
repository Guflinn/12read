这一版是一次集中排版打磨：**六轮试用反馈全部落地**，阅读器的字号、行距、字间距、栏宽、字体从此都能自己调了。

## 新增

- **阅读器两侧的切章箭头** —— 正文两侧各一枚悬浮箭头，垂直居中、不随滚动跑：长章节刚打开还没读到下面时，不用滚到底找按钮、也不用开目录，点一下就能切上一章 / 下一章（悬停浮出「下一章：xxx」提示）。平时半透明不抢眼；第一章 / 最后一章各自隐藏；「全宽」栏宽下不渲染。键盘 Ctrl + ← / → 与底部按钮照旧。
- **栏宽新增「特大」档**（68rem ≈ 1088px）—— 大屏 / 4K 全屏下「宽」两侧留白太多、「全宽」一行又太长，中间多一档。
- **行距自由微调** —— 原来「紧凑 / 标准 / 宽松」三个固定档改成 ± 步进（1.20 – 3.00，每下 0.05）。
- **字间距调节** —— 觉得字挤就拉开：± 步进（0 – 0.30em，每下 0.01）。
- **新增「黑体」字体**（打包思源黑体 Noto Sans SC，与苹方同为现代黑体风格）。

## 调整

- **字号上限 32 → 56**（默认 22）—— 大屏离远了也能调大。
- **字体列表（六款）**：宋体（默认）/ 仿宋 / 楷体 / 黑体 / 文楷 / 思源宋。经典宋体、仿宋、楷体用 Windows 系统自带；文楷（霞鹜文楷）、思源宋（Noto Serif SC）、黑体（Noto Sans SC）三款开源字体（OFL 许可）直接打包进应用，**不用安装**。
- **加粗更克制** —— 不再用「合成粗体」把笔画硬加粗一截（那样字会糊成一团），改成 0.35px 细描边：视觉变重、笔画均匀。
- **Aa 面板点空白处自动关闭**（再点一下 Aa 收回的开关照旧好使）。
- **箭头往内收 24px**，不再压在滚动条上。

## 说明与取舍

- **改排版设置（字号 / 行距 / 字距 / 栏宽 / 字体）正文会重新排版，但阅读位置不变** —— 进度按字符偏移记录，不用「第几页」。
- 打包的三款开源字体都只有常规字重，「加粗」走细描边而不是合成粗体。
- 窗口尺寸与位置、阅读统计、书签划线、搜索、备份等既有功能不受影响；老设置自动兼容（缺的选项补默认值，字体设置自动对应到新列表）。

这一版加**第三种书籍格式：MOBI**，另有两件关于字体的事：新增「中宋」字体，以及**加粗改成三档**（你想多粗、多轻自己拨）。

## 新增

- **MOBI 导入**（`.mobi`，即 MOBI6 / KF7；无 DRM 的那种）—— 拖进书架或点「导入书籍」选它都行：
  - **书名、作者、封面**都直接读文件里自带的（文件名乱起也没关系）；
  - **章节**按书里的翻页标记切，封面页、目录页会自动认出来；
  - **正文里的插图**像 EPUB 一样内联显示；
  - 书封面上点「提取」可以用最新逻辑重跑一遍，不用重新导入。
- **新增字体档「中宋」** —— 就是 Windows 中文版自带的**华文中宋**：比正文书宋笔画更壮、字形更端正饱满（公文标题那一挂的风格）。**这一档不打包字体文件**，系统里装了就直接用；安装包不会因此变大，也没有商业字体的授权问题。
- **加粗改成三档：关 / 轻 / 中**（在 Aa 面板里）：
  - **轻**：只加粗竖画，横画保持纤细锐利 —— 力度和你原来用的加粗一样，但**不再发虚**；竖画加得比宋体本身粗约 48%，观感接近「中宋」。
  - **中**：横竖一起加粗，明显更黑更壮。

## 调整

- **修掉「一开加粗就发虚」**：老实现是给文字描 0.35px 的细边，那圈是半透明的，正好落在宋体细横的两侧 → 把一行的实墨摊成两三行浅墨。现在改成叠加**整份的字形副本**（不透明），边缘是实边。
- **思源宋换成可变字体**（wght 200–900）—— 这一版仍按常规粗细渲染，观感不变；意义是**以后要调粗细只需改一个数字**。代价：解包后体积 +13MB（安装包 128.3MB → 132.4MB）。
- **老设置自动迁移**：你原来开着加粗，升级后落在「轻」（力度不变）；其余设置、书架、阅读进度都不受影响。

## 说明与取舍

- **MOBI 只做常规情形**：**MOBI6 / KF7**、**不压缩 / PalmDOC**、**无 DRM**。碰到 **KF8（`.azw3`）**、**Huff/CDic 压缩**、**带 DRM** 的书会明确告诉你读不了，并建议用 Calibre 转一次 —— 这三类不做，也不会打马虎眼假装支持。
- **加粗为什么只有两档**（不是偷懒）：字体没有粗体文件时只能做伪粗体，而要让加粗的边缘"实"，副本就必须错开**整数个屏幕像素**；宋体的横画只有约 1.1 个屏幕像素宽，所以最小的一步（轻）就已经是 +30% 落墨，再上一步（中）是 +98% —— 中间那档在像素栅格上不存在，用半个像素则边缘必然半透明（那就是发虚）。
- **Windows 自带的宋体没有粗体文件**，所以「加粗」对它是模拟的；思源宋、中宋、黑体、文楷这些自带真笔画的字体，加粗观感会更自然。
- 顺带一提：每款字体的"粗细"是设计时定死的，不是越粗越好读 —— 选哪档以眼睛舒服为准。

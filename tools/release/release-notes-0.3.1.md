这一版只有一件事：**应用有了自己的图标** —— 纸色圆角底上的宋体字标「十二」，右上角压一枚朱红书签。装上以后，桌面快捷方式、任务栏、开始菜单和资源管理器里都能一眼认出它。

## 新增

- **应用图标**：
  - 字形用**思源宋体**（OFL 开源协议）渲染成位图 —— 不打包、不内嵌任何商业字体字节，与本项目的字体授权红线一致；
  - 图标源文件是矢量，16px 任务栏小图到 256px 大图全部由同一份源出图，小尺寸下「十二」与书签仍清晰可辨。

## 说明与取舍

- 图标方向上没选「翻开的书」这类通用阅读符号——那类图标和微信读书、Kindle 撞脸；也没做表盘双关——细节在小尺寸下会糊成一团。最后选了最稳的**字标**：两个汉字对比度高，缩到 16px 依然认得出。
- 顺带修了一个**测试环境**问题：zip 备份的独立校验测试在 GNU tar 排在 PATH 前面的机器上会误报（它把 `C:\` 当远程主机名），现在显式用 Windows 自带的 bsdtar（Explorer 解 zip 同款）。**只影响测试，不影响应用任何功能**。

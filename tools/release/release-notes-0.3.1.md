这一版只有一件事：**应用有了自己的图标** —— 纸色圆角底上的宋体字标「十二」，右上角压一枚朱红书签，带一层柔和投影。装上以后，桌面快捷方式、任务栏、开始菜单和资源管理器里都能一眼认出它。四角是透明的，桌面上看到的就是一个干净的圆角卡片。

## 新增

- **应用图标**：
  - 字形用**思源宋体**（OFL 开源协议）渲染成位图 —— 不打包、不内嵌任何商业字体字节，与本项目的字体授权红线一致；
  - 图标源文件是矢量，16px 任务栏小图到 256px 大图全部由同一份源出图，小尺寸下「十二」与书签仍清晰可辨。
- **免安装版**：本次起随 Release 提供 `twelve-read-0.3.1-portable.zip` —— 下载后**右键「全部解压缩」**（Windows 自带功能，不用装任何解压工具），打开解出的 `twelve-read-0.3.1` 文件夹，双击 `十二阅读.exe` 就能用。

## 修正（发布同日）

- 首发的图标**四角被拍成了白底**（渲染时透明区域丢失），桌面上看着是方块；当天已修复并换上本页的安装包 —— 图标四角透明 + 加了投影。以本页当前附件为准。

## 说明与取舍

- 图标方向上没选「翻开的书」这类通用阅读符号——那类图标和微信读书、Kindle 撞脸；也没做表盘双关——细节在小尺寸下会糊成一团。最后选了最稳的**字标**：两个汉字对比度高，缩到 16px 依然认得出。
- **免安装版体积**：解压后约 409MB，压缩包 174MB —— 这是 Electron 应用的正常体积（内置 Chromium 运行时占 300MB+）。
- 顺带修了一个**测试环境**问题：zip 备份的独立校验测试在 GNU tar 排在 PATH 前面的机器上会误报（它把 `C:\` 当远程主机名），现在显式用 Windows 自带的 bsdtar（Explorer 解 zip 同款）。**只影响测试，不影响应用任何功能**。

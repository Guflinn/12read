这一版只有一件事：**应用有了自己的图标** —— 纸色圆角底上的宋体字标「十二」，右上角压一枚朱红书签。桌面快捷方式、任务栏、开始菜单和资源管理器里都能一眼认出它。

## 新增

- 🎨 **应用图标**
  字形用**思源宋体**（OFL 开源协议）渲染成位图 —— 不打包、不内嵌任何商业字体字节；图标源文件是矢量，16px 任务栏小图到 256px 大图由同一份源出图，小尺寸下「十二」与书签仍清晰可辨。
- 📦 **免安装版（单文件 exe）**
  本次起随 Release 提供 **`twelve-read-portable-0.3.1.exe`** —— 下载后**双击直接运行**，不安装。首次启动它会在后台释放一次文件（等几秒到几十秒窗口才出现），之后启动就正常了。书库、设置与安装版**共用同一份**，两边都能看到你的书。

## 修正（发布同日）

- 🩹 **首发的图标四角被拍成了白底**（渲染时透明区域丢失），桌面上看着是方块；当天已修复 —— 图标四角透明 + 柔和投影。**以本页当前附件为准。**

## 说明与取舍

- **图标方向**：没选「翻开的书」这类通用阅读符号（和微信读书、Kindle 撞脸），也没做表盘双关（小尺寸糊成一团）；选了最稳的**字标** —— 两个汉字对比度高，缩到 16px 依然认得出。
- **免安装版体积**：单文件 exe 共 119,450,356 字节（约 114 MB）；Electron 应用的运行文件解出来约 409 MB（内置 Chromium 运行时占 300 MB+），这是同类应用的正常体积。
- **测试环境修正**：zip 备份的独立校验测试在 GNU tar 排在 PATH 前面的机器上会误报，已改为显式用 Windows 自带的 bsdtar。只影响测试，不影响应用任何功能。

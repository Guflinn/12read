这一版是**格式与应用能力的补齐**：现在能读 **Markdown** 与**有文字层的 PDF**（一共五种格式），书库可以**整库备份还原**，装完安装版之后还能**在应用内更新** —— 有新版本点一下就地下载、重启即装，不用再去网页找安装包。

## 新增

- 📝 **Markdown（.md）**
  拖进窗口或从「导入书籍」里选。按 `#` 标题切章，标题 / 引用 / 列表 / 代码块 / 分隔线 / 粗斜体与行内代码都按样渲染；书封面上点「编码」也能换编码重解（和 TXT 同一条路）。
  *取舍*：表格、任务列表、脚注不做；链接与图片只做样式（点不开、不加载网络图片）；搜索命中处会看到原始标记（搜索是对原文做的，这样位置才准）。
- 📄 **PDF（有文字层的）**
  优先按书自带的目录切章，没目录就按页分章（「第 1 页」「第 2 页」…）；段落靠坐标还原 —— 中文换行不会多出空格，西文换行会补空格；书名作者取自 PDF 的文档信息。
  *边界*：**扫描件**（整本没有文字、正文其实是图片）会明确告诉你读不了；带密码的 PDF 直接说打不开。**不承诺排版保真** —— 缩进、表格、分栏都不可靠，PDF 的版面本来就是固定的。
- 💾 **备份还原**
  以前只能导出；现在能从导出的 zip **整库还原**。还原前会把当前书库整份挪到数据目录下的 `restore-undo-<时间>`（不是删，可反悔），换完自动重启。备份包里只放原始文件，所以重启时会自动把正文重新提取一遍补齐。
- 🔄 **应用内更新（安装版）**
  书架左下角发现新版本时，点一下就地下载（带进度百分比），下好变成「已下载 vX · 重启并更新」。走差量更新，日常版本只下几 MB，并校验文件校验和；**下载完不会偷偷装**，必须你点「重启并更新」。
  *免安装版不支持自更新*（它是自解压到临时目录跑的，没有可替换的安装位置），点下去会明说并打开下载页。

## 修复

- 🩹 **关窗可能弹「A JavaScript error occurred in the main process」** —— 还原备份之后关窗会撞上「数据库连接已经关了、却还在写窗口位置」，异常出在主进程的事件回调里，会弹框并把退出卡住（点掉再关又弹）。现在这类收尾写入会先问一句「连接还在吗」，写不进去就跳过。
- 🩹 **导入 PDF 可能把应用直接打崩**（表现为「十二阅读 has stopped working」）—— pdfjs 会去加载一个自带的 skia 原生模块，它在 Electron 里加载会崩。已改成用一份纯 JS 的小替身顶掉它。
- 🩹 **还原失败的原因现在看得见**：从备份还原如果中途失败（会自动回滚），会先用系统弹窗说清原因、并说明「已退回还原前的书库，你的书和进度都在」，再重启。
- 🩹 顺带给「挪旧书库」那两步加了重试（Windows 上别的进程短暂占用库文件就会让改名失败，一次失败就会让整次还原作废）。

## 说明与取舍

- **应用内更新从这一版开始才有**：这一版之前的版本里没有更新器，所以第一次升级仍然要手动下载安装包；**从 0.4.0 升到以后的新版本就可以在应用内点着升级了**。免安装版永远走手动替换。
- **体积**：两个包都在 126 MB 左右（比上一版多约 12 MB），多出来的是 PDF 解析库与更新器。
- **PDF 的定位**：能做的是「把文字层老老实实抽出来读」，不是「PDF 阅读器」—— 固定版面不可能重排，扫描件也不做 OCR。要读扫描件请先用别的工具转成文字版。
- **备份包仍然只在本地**：应用不联网，备份文件放哪儿由你决定。
- 测试：本版交付前跑过单测 + 契约 67 个文件 / 804 例、端到端 56 例，全部通过。

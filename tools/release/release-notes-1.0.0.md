十二阅读 **1.0.0 正式版**来了 —— 内测结束。这一版**没有新功能、也没有修复**：功能集与 0.4.0 完全一致

从 0.1.0 到 0.4.0 一共十个内测版本，格式、性能与稳定性都打磨到位了，可以正式日常用了。

> 已经在用 0.4.0（安装版）的话，**书架左下角过一会儿就会看到这个 1.0.0 的更新** —— 点一下就地下载、
> 「重启并更新」就升上来了。这也是应用内更新器上线以来第一次真跑，欢迎替我们踩一遍。

## 这一版里有什么（自 0.3.1 起的全部能力）

- 📚 **五种格式**：TXT / EPUB / MOBI / **Markdown** / **PDF（有文字层的）**，拖进来就能读；
  进度、书签、划线、搜索、统计在所有格式上是一套。
- 🔄 **应用内更新（安装版）**：有新版点一下就地下载（差量、带进度），下好点「重启并更新」；
  **不会偷偷装**。免安装版不支持自更新，会明说并打开下载页。
- 💾 **备份还原**：一键导出整库 zip，也能从备份**整库还原**（还原前自动留一份旧的，可反悔）。
- 🩹 以及 0.4.0 带的两个崩溃修复（关窗弹错、导入 PDF 打崩应用）。

更早的能力（字体排版 / 书签划线 / 全书搜索 / 阅读统计 / 分章可修等）见 [README](https://github.com/Guflinn/12read#readme)。

## 下载

> ⚠️ **页面下方 Assets 区里的文件名只能是英文** —— GitHub 会把 Release 附件名里的中文**直接删掉**
> （实测：`安装包-1.0.0.exe` → `-1.0.0.exe`、`测试中文名.txt` → `default.txt`），没得商量。
> 所以**请点下面这两个中文链接下载**，包本身和 Assets 里那两个完全一样（同一份文件）。

- ⬇️ **[安装版 · 推荐（装了以后能应用内更新）](https://github.com/Guflinn/12read/releases/download/v1.0.0/twelve-read-setup-1.0.0.exe)**（约 126 MB，对应 Assets 里的 `twelve-read-setup-1.0.0.exe`）
- ⬇️ **[免安装版 · 单文件双击即用](https://github.com/Guflinn/12read/releases/download/v1.0.0/twelve-read-portable-1.0.0.exe)**（约 126 MB，对应 Assets 里的 `twelve-read-portable-1.0.0.exe`）

两个包都是：**已装旧版直接覆盖安装**，书库、设置与阅读进度都在。免安装版首次启动会自释放一次，稍等几秒。
Assets 区里的 `latest.yml` 与 `*.blockmap` 是应用内更新的元数据（差量下载用），**不用手动下载**，留给应用自己取。

> **想要中文文件名**：下载后自己重命名即可 —— 「十二阅读安装版.exe」「十二阅读免安装版.exe」随便叫，

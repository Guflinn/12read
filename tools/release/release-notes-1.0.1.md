# 十二阅读 v1.0.1（Windows）

这一版只做一件事：**把「备份还原」修好**。1.0.0 里有用户反馈：还原备份后应用会自己退出、再也不回来（看着像闪退）。1.0.1 彻底重做了这条路 —— **还原全程应用不退出**。

## 修复

- **还原备份后应用不再退出**：旧版还原完会重启应用，而「退出再启动」这一步在部分机器上不可靠（应用退了、新实例没起来，看起来就像闪退）。现在改成**原地重接**：换完库文件直接在进程内重新打开新库、把书架/进度/书签/划线全部接上，窗口都不关。还原完成后点一下「**刷新书架**」就能看到备份里的书。
- **还原过程中不再弹红色错误条**：还原要花几秒（换库文件 + 自动补正文），这期间书架如果刷新一次，旧版会报「读取书架失败：The database connection is not open」。现在这几秒里的请求会安静排队，等新库就位后直接拿到正确结果。
- 还原失败的兜底保留：万一换库写到一半失败，会自动退回还原前的书库（`restore-undo-<时间>` 文件夹里），失败原因会用系统弹窗讲清楚。

## 说明与取舍

- **1.0.0 → 1.0.1 应用内更新不可用**：与本系列一贯的取舍一致（Release 附件只放两个 exe，不带更新元数据），装了 1.0.0 的用户请手动下载覆盖安装 —— **书库数据不受影响**（数据存在本机数据目录，与程序目录无关），安装版直接双击新版 setup 覆盖装，免安装版下载新 exe 替换旧的即可。
- 免安装版与安装版功能一致，本次修复对两者同样生效。

## 安装说明

- **安装版**：下载 `twelve-read-setup-1.0.1.exe`（132,587,514 字节），双击安装。已装旧版本可直接覆盖安装，书与进度都在。
- **免安装版**：下载 `twelve-read-portable-1.0.1.exe`（132,352,557 字节），双击即用，无需安装；首次启动自解压，稍等一两秒。

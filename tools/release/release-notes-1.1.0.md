# 十二阅读 v1.1.0（Windows）

这一版只加一样东西：**新字体档「秀楷」**。打开阅读器顶栏的 **AA**，字体一行最后多了一个「秀楷」，点它正文就换成方正宋刻本秀楷 —— 一种复刻自宋代刻本的楷体，简体繁体的书都能显示。

## 新增

- **字体档「秀楷」**：打包方正宋刻本秀楷 简繁（GBK）Regular。已获得方正「软件内置字体应用授权」（按应用名授权）。静态单字重（常规），「加粗」开关照常可用；未选择该档的用户不受任何影响，默认字体仍是宋体。

## 说明与取舍

- **1.0.0 / 1.0.1 → 1.1.0 应用内更新不可用**：与本系列一贯的取舍一致（Release 附件只放两个 exe，不带更新元数据），请手动下载覆盖安装 —— **书库数据不受影响**（数据存在本机数据目录，与程序目录无关），安装版直接双击新版 setup 覆盖装，免安装版下载新 exe 替换旧的即可。
- 免安装版与安装版功能一致。

## 安装说明

- **安装版**：下载 `twelve-read-setup-1.1.0.exe`（136,222,246 字节），双击安装。已装旧版本可直接覆盖安装，书与进度都在。
- **免安装版**：下载 `twelve-read-portable-1.1.0.exe`（135,987,225 字节），双击即用，无需安装；首次启动自解压，稍等一两秒。
